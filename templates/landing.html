About

A folder-first workspace with AI suggestions.

File Nest keeps uploads, folder notes, search, and statistics in one practical dashboard. AI helps recommend where files could go, but the user confirms the final destination.

System overview

Folders stay central

Every file belongs to a clear folder with color, icon, count, and notes.

Protected accounts

Supabase Auth handles login, password reset, and account changes.

Private storage

Metadata stays in Postgres while uploaded files live in private storage.

Helpful AI

Gemini and TextBlob assist with recommendations, not final sorting.

Instructions

Five steps from upload to organized storage.

Create folders, upload files, review recommendations when needed, then manage everything from the folder and file views.

Simple flow
1

Create folders

Name folders clearly and use colors/icons for quick scanning.

2

Upload files

Choose direct upload or ask for AI folder suggestions.

3

Review AI

Accept the recommendation or choose a better folder yourself.

4

Manage files

Preview, rename, move, download, sort, or delete files.

5

Track activity

Use the dashboard and statistics to monitor file activity.
