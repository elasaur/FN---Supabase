Features

Everything for a cleaner file workspace.

AI-assisted organization

Analyze file names and supported document content to suggest folders while keeping final confirmation in your hands.

Custom folders

Create folders with clear labels, colors, and icons, then pin important folders to keep them easy to reach.

Guided uploads

Upload directly into a selected folder or ask the system to analyze and recommend the best destination.

Search and file actions

Find files quickly, preview them, rename them, move them between folders, download copies, or delete old items.

Statistics

See file type breakdowns, folder distribution, recent upload activity, and AI sorting summaries.

Private storage model

Accounts, file metadata, and stored files are backed by Supabase services with private storage access.

Instructions

How to use File Nest.

How to use

Start with folders, upload files, then let the system keep things easy to scan.

Use these steps when setting up a workspace for the first time or when adding a new batch of files.

1

Create folders

Name your folders clearly, choose a color and icon, and pin the folders you use often.

2

Upload files

Choose a file, then save it directly or run AI analysis for a folder recommendation.

3

Review suggestions

Check the AI result, confirm the suggested folder, or choose another destination.

4

Manage files

Preview, rename, move, download, sort, or delete files from All Files and folder views.

5

Track activity

Use Home and Statistics to review recent uploads, file types, folder counts, and AI activity.

About the system

An AI-assisted file organization system.

What File Nest does

File Nest helps users upload, classify, store, retrieve, and manage files through a dashboard built around folders, recent activity, search, and storage statistics.

The system keeps the user in control. AI can recommend where a file belongs, but the user confirms the destination before the upload is saved.

Authentication

Supabase Auth handles accounts, sign in, reset password, and credential changes.

Data and storage

Supabase PostgreSQL stores metadata while private Supabase Storage keeps uploaded files.

AI analysis

Gemini-based analysis can inspect supported content, with TextBlob and keyword fallback logic.
