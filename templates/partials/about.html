About the System
What File Nest is, how it works, and what powers it.
System overview

File Nest is an AI-assisted file organization system.

It helps users upload, classify, store, retrieve, and manage files through Home, which is built around folders, recent activity, search, and storage statistics.

The system keeps the user in control: AI can recommend where a file belongs, but the user confirms the destination before the upload is saved.

Authentication

Supabase Auth handles user identity, sign in, password reset, and account-level credential changes.

Data and storage

Supabase PostgreSQL stores users, folders, and file metadata. File bytes live in private Supabase Storage.

AI analysis

Gemini-based analysis can inspect supported file content, with TextBlob used when Gemini reaches its limit.
