Instructions
How to use File Nest from upload to retrieval.
How to use

Start with folders, upload files, then let the system keep things easy to scan.

Use these steps when setting up a workspace for the first time or when adding a new batch of files.

Tip

Name folders clearly so AI suggestions have better labels to match against.

Review

AI recommendations are not final until you confirm the upload destination.

Access

Use Settings to update account details, change your password, or manage account removal.

1

Create your folders

Open All Folders, create a folder, choose a color and icon, then pin the folders you use most often.

2

Upload a file

Open Upload Files, choose or drag in a file, then decide whether to save it directly or run AI analysis first.

3

Review AI suggestions

When analysis is enabled, review the suggested folder and confidence result. Confirm the suggestion or choose a different folder.

4

Manage saved files

Use All Files or a folder view to preview, rename, move, download, or delete files. Sort chips help narrow what you are scanning.

5

Search and monitor activity

Use the top search field to find files quickly. Check Home and Statistics for recent uploads, file types, folder counts, and AI activity.
